## What This Project Does

Daily analytics pipeline for the Hyperliquid protocol. Every day at **12:00 Beijing time (04:00 UTC)** a cron job runs and produces:

1. `logs/YYYY-MM-DD.md` — the `$HYPE` morning brief (price, revenue, valuation, market commentary)
2. `hyperliquid_6m_macro_trend.png` — 6-month macro trend chart (overwritten each run)
3. A row written to `hyperliquid_stats.db` with that day's metrics
4. `dashboard.html` — interactive dashboard (gitignored, regenerated fresh each run, not committed): macro chart, morning brief, a live USDC-float chart + AQA/AQAv2 reserve-income estimate, and an interactive $HYPE P/S explorer

The revenue breakdown (`generate_revenue_breakdown.py`) is **separate** and run manually on request.

## Database

Single table: `daily_metrics`

```
date TEXT (PK), hype_price, hype_1d_chg, hype_7d_chg, hype_30d_chg,
btc_price, btc_1d_chg, btc_7d_chg, btc_30d_chg,
revenue_daily, revenue_7d_avg, revenue_30d_avg, revenue_7d_vs_30d,
created_at, hype_circulating_supply, hype_total_supply,
hype_circulating_pct, hype_market_cap, hype_ps_ratio
```

**Revenue column semantics**: `revenue_daily` is DefiLlama `dailyRevenue` for all Hyperliquid sources minus a small Spectra V2 adjustment. It is **net protocol revenue** as reported by DefiLlama, not gross trading volume.

To query: `sqlite3 hyperliquid_stats.db "SELECT date, revenue_daily FROM daily_metrics ORDER BY date DESC LIMIT 10"`

## Data Sources

### DefiLlama (revenue)
```
https://api.llama.fi/overview/fees/hyperliquid?excludeTotalDataChart=false&excludeTotalDataChartBreakdown=false&dataType=dailyRevenue
```
- Returns daily revenue broken into source buckets: `Hyperliquid Perps`, `Hyperliquid Spot Orderbook`, `Hyperliquid HLP`, plus ~200 ecosystem apps
- **Does NOT** expose per-coin/per-market breakdown. Only three top-level protocol buckets
- Data for day D settles ~4 hours after UTC midnight. The cron runs at 04:00 UTC to give buffer

### Hyperliquid API
```
https://api.hyperliquid.xyz/info  (POST, JSON body)
```
Key request types:
- `{"type": "metaAndAssetCtxs"}` — all native perp markets with current price, OI, funding, `dayNtlVlm`
- `{"type": "perpDexs"}` — HIP-3 builder dex metadata: deployer address, `deployerFeeScale`, `assetToStreamingOiCap` (list of `[market_name, cap]` pairs)
- `{"type": "candleSnapshot", "req": {"coin": "BTC", "interval": "1d", "startTime": MS, "endTime": MS}}` — OHLCV candles. `v` field is base-asset volume; multiply by `(o+c)/2` to get USD notional
- `{"type": "globalStats"}` — `{"totalVolume": ..., "dailyVolume": ..., "nUsers": ...}` (aggregate only)

**What the HL API does NOT expose**: historical protocol fee revenue per market. Per-market fee revenue requires L1 transaction-level data.

### CoinGecko (HYPE/BTC prices + supply)
Used for price data and circulating supply. See `plot_macro_trend.py` for exact endpoint.

## Cron / Automation

- **Trigger**: macOS launchd, plist at `~/Library/LaunchAgents/com.hyperliquid.dailyreport.plist`
- **Time**: 12:00 local (Beijing) = 04:00 UTC
- **Rationale**: DefiLlama revenue for UTC day D-1 needs ~4 hours to settle after UTC midnight
- **Logs**: `logs/launchd.out.log`, `logs/launchd.err.log`, `cron.log`
- **Manual trigger**: `./run_daily_report.sh YYYY-MM-DD`

To check cron status: `launchctl list | grep hyperliquid`

## What NOT To Do

- **Do not** use `volume × blended_rate` to estimate per-market revenue — different venues have radically different per-notional protocol rates (native 3+ bps vs HIP-3 ~0.4 bps)
- **Do not** treat HIP-3 volume as proportional to HIP-3 protocol revenue
- **Do not** query `daily_revenue` table in SQLite — it doesn't exist. The only table is `daily_metrics`
- **Do not** assume DefiLlama data is settled before ~04:00 UTC the next day
- **Do not** use live `dayNtlVlm` from `metaAndAssetCtxs` as a proxy for a specific historical day's volume — it's today's rolling 24h figure
- **Do not** hardcode the native/HIP-3 revenue split (93.1%/6.9%) as a universal constant — it's a June 2026 monthly average from ASXN; it varies by day
